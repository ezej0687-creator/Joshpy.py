# Capstone Projects

Choose one project after completing the lessons. Keep the first version small;
add extra features only after the basic version works.

## 1. Command-line quiz

- Ask questions and accept answers.
- Keep score in a dictionary or a small class.
- Validate input and handle unexpected answers.
- Save the score to a JSON file.
- Add tests for scoring.

## 2. Personal reading tracker

- Add, list, and mark books as finished.
- Store each book's title, author, and status.
- Save and load the collection as JSON.
- Separate the data operations into functions.
- Add tests for adding and finding books.

## 3. Expense summary

- Read expenses from a CSV file.
- Validate dates and amounts.
- Group spending by category.
- Print totals and a simple summary.
- Test the calculations with sample data.

## Project checklist

- [ ] The program has a clear, small first feature.
- [ ] Functions have focused responsibilities and useful names.
- [ ] Invalid input produces a helpful message.
- [ ] Data is saved and loaded when the project needs persistence.
- [ ] Important behavior has tests.
- [ ] The README explains how to run the project and gives an example.
